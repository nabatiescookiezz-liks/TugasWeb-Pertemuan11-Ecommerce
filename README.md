# Tugas Web Pertemuan 11 — E-Commerce

Aplikasi E-Commerce berbasis Laravel untuk memenuhi tugas mata kuliah Pengembangan Web.

## Teknologi
- Laravel
- PHP
- MySQL
- Blade

## Fitur
- Autentikasi pengguna
- Menampilkan daftar produk
- Fitur E-Commerce sesuai implementasi aplikasi

## Menjalankan Aplikasi
1. Install dependensi menggunakan `composer install`.
2. Salin `.env.example` menjadi `.env`.
3. Atur konfigurasi database pada file `.env`.
4. Jalankan `php artisan key:generate`.
5. Jalankan migrasi database menggunakan `php artisan migrate`.
6. Jalankan aplikasi dengan `php artisan serve`.
